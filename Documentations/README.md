# Project Documentation

This folder contains all the relevant documentation for the **Rail DSS** project, including:

* Presentations (.ppt, .pptx)
* Reports and Guides (.pdf)
* Demo Videos (.mp4, .mkv, etc.)

> **Note on Video Files:** GitHub has a strict file size limit of **100 MB per file**. If your demo video is larger than 100 MB, you should either compress it, use Git LFS (Large File Storage), or upload the video to YouTube/Google Drive and link it here instead.
